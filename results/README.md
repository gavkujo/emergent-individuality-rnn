# Results

Experiment outputs. Generated by `run_*.py` scripts via `src/results_io.save_result`.

## Layout

```
results/
  week<NN>_<YYYY>/
    <name>_<YYYYMMDD>_<version>.json
```

Week numbering is ISO week (Mon–Sun). Each JSON has these mandatory keys:

- `name` — experiment name (matches the filename prefix)
- `description` — what the experiment does, one line
- `details` — what changed from previous versions
- `time` — ISO-8601 timestamp, second precision
- `results` — the actual experiment payload

## Reading the latest result

```python
from src.results_io import load_latest
payload = load_latest("benchmark")     # searches all week folders
results = payload["results"]
```

`load_latest` returns the most recently dated file matching that name across
all week folders, so consumer scripts (`run_figures.py`, etc) keep working
even after the week rolls over.

## Do not edit these files by hand

They are generated. If you need to record interpretation, write a `.md` in
the matching `findings/week<NN>_<YYYY>/` folder and reference the JSON path.
